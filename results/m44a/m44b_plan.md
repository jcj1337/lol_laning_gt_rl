Seeds 0, 1, 2 in every environment: a seed fixes the initial network and the collector streams, so the three environments start each seed from bit-identical weights (paired initialization).

## Commands

- **train**: `python -m lanegame.experiments.rl.m44 train_main --confirm-m44b --workers 9` — 9 runs (3 environments x seeds 0, 1, 2) of 2,048,000 agent transitions, one process each
- **evaluate**: `python -m lanegame.experiments.rl.m44 eval_main --workers 9` — load / digest checks, references (W = 1000), cross-play, history, learning curves, behaviour diagnostics, counterfactuals, viewer traces -> results/m44b/eval_main.json(.gz)
- **one environment only (example)**: `python -m lanegame.experiments.rl.m44 train_main --confirm-m44b --envs aggro --workers 3` — the same runs restricted to one environment (identical settings)

## Training settings (identical in every environment)

| setting | value |
|---|---|
| algorithm | PPO, clipped surrogate 0.2, value clip 0.5, 4 epochs, minibatch 256, Adam 3e-4 annealed |
| self-play | shared policy, 100% current-policy games (both seats trained) |
| entropy coefficient | 0.03 |
| gamma / GAE lambda | 0.99 / 0.95 |
| rollout | 16 environments x 128 turns x 2 seats = 4096 transitions per update |
| games | 512 turns, bootstrapped truncation (never terminated) |
| reward scale | 0.1 |
| network | 88 -> 128 -> 128 (tanh) -> 61 masked logits + value |
| budget | 2,048,000 agent transitions = 500 updates |
| snapshots | every 25,600 transitions |

## Comparisons

- econ vs aggro (same economy, tower retaliation on busy dives only): dive frequency, busy-dive rate, tower shots taken, defender reply to dives, Vision before pressure, deaths per 1000 turns
- four vs econ / aggro (the broader control): Shove share by state and by plate phase, freeze episodes, concession under a credible threat, references and cross-play values
- within each environment: seed-to-seed spread (3 seeds; t interval with 2 degrees of freedom, t = 4.30) before any between-environment claim

## Caveats

- three seeds per environment is a starting comparison, not a convergence guarantee
- the budget (2,048,000) equals the M4.3b / M4.3c pilot budget; whether policies have converged is read from the learning curves (value against fixed references and against the own snapshots), not assumed
