# Artifacts

The curated, tracked outputs of the research. Everything else a run produces goes to the git-ignored `runs/`
(`lanegame/paths.py`). These files were curated on 2026-11-08 from the former `results/` directory, whose remaining
files (raw per-job records, partial results, run logs and screenshots, 1,548 files and 326 MB) are at commit
[`f613f0a0`](https://github.com/jcj1337/lol_game_theory_laning/tree/f613f0a00a2d46fe717de7e8c79077fa9e0310c3).
Kept files are byte-identical to their originals ([MOVES.md](../docs/archive/MOVES.md) lists every one with its
SHA-256).

## What is here

| category | location | contents |
|---|---|---|
| demo networks | `checkpoints/` | the 7 networks the demo plays and believes over, at their original relative paths; `lanegame/demo/manifest.json` lists them with SHA-256 and the registry verifies every file before it loads any |
| final campaign | `m5/` | M5's complete records: the pre-registration chain (`preregistration.json`, `prereg_versions/`), training, health, evaluation, battery and attacker summaries, `analysis_main.json`, `strategic_main.json`, `monitoring_main.json`, `report.md`, the reproducibility manifest (`reproducibility.md`, `inventory.json`, `inventory_files.json.gz` with the SHA-256 of 429 networks and every record) and the 15 viewer recordings in `traces/` (the demo replays three) |
| latest study | `nc1/` | NC1's complete records |
| model examples | `reference/` | the engine-computed examples that [the model](../docs/model.md) quotes (`report.md`) |
| Phase 1 | `siege/`, `revision/`, `v1/` | the exact game's tables and figures; `siege/solution_K32_summary.json` keeps the K = 32 solution's configuration, value and statistics (the 68 MB solution is regenerated by `python -m lanegame solve --horizon 32`) |
| earlier studies | one directory per study (`m4/` to `m48/`, `om1/`, `om2/`, `rl/`, `champions/`, `m4_*`) | each study's generated tables (`report.md` and companions), figures and pre-registration or protocol records |
| demo verification | `m6/` | the M6a re-checks and measurements, the M6b and M6c browser verdicts, the overview check, two regression logs and the site screenshots (`site/`) |

## Conventions

- A study whose package is maintained writes its summaries here (`experiments/<study>/`, `OUT`) and its raw outputs
  and checkpoints to `runs/` (`CKPT`). Re-running a deterministic stage rewrites its file byte for byte; a difference
  shows in `git diff`.
- Records are never rewritten by hand. Paths inside records written before 2026-11-08 use the old layout
  (`results/<study>/`, `results/rl/checkpoints/`); `lanegame.paths.relocated` maps them.
- A checkpoint path under `runs/checkpoints/` that is missing falls back to the shipped copy here
  (`lanegame.paths.checkpoint`), so a fresh clone can load the demo networks by their M5 names (`sp:0`, `om:0`).
- `.gitignore` ignores every `*.pt` except those under `artifacts/checkpoints/`.
